How to read this map

  1. Read left → right: data moves through stages — authority, intake, collection, data, custody, then to decision surfaces.
  2. Solid cyan = documented: a public record says this flow exists.
  3. Dashed amber = authorized: a law permits it; no public evidence it happens. Faint amber is an authorization note, not a data flow.
  4. Dotted purple = inferred: composition makes it derivable, though no one disclosed it.
  5. Click any box or line for a plain-language explanation and its receipts. Hover a box to isolate its connections.
